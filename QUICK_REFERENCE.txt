┌──────────────────────────────────────────────────────────────────┐
│ 🔄 RESTORE A VERSION                                             │
└──────────────────────────────────────────────────────────────────┘
  1. Click "Restore to version XXX" in Figma Make
  2. Edit /src/app/utils/versionManager.ts
     → export const APP_VERSION = 'XXX-restored'
  3. Reload browser (F5)
  4. Look for green "Cache Cleared" badge ✅
  5. Test performance

┌──────────────────────────────────────────────────────────────────┐
│ 🔍 CHECK IF RESTORATION WORKED                                   │
└──────────────────────────────────────────────────────────────────┘
  In browser console (F12):
  
  window.checkAppVersion()
  → Should show matching versions
  
  window.runDiagnostics()
  → Check FPS, GPU, canvas settings

┌──────────────────────────────────────────────────────────────────┐
│ 🧹 MANUAL CACHE CLEAR (if needed)                                │
└──────────────────────────────────────────────────────────────────┘
  In browser console:
  
  window.forceClearAllCache()
  location.reload();

  OR:
  
  localStorage.clear();
  sessionStorage.clear();
  location.reload();

┌──────────────────────────────────────────────────────────────────┐
│ 🚨 STILL SLOW AFTER RESTORATION?                                 │
└──────────────────────────────────────────────────────────────────┘
  1. Test in Incognito mode (Ctrl+Shift+N)
     → If fast: Browser extension or cache issue
     → If slow: Continue to step 2
  
  2. Run diagnostics:
     window.runDiagnostics()
     → Check GPU renderer (should NOT be "SwiftShader")
     → Check FPS (should be 30+)
  
  3. Hard refresh:
     Ctrl+Shift+R (Windows)
     Cmd+Shift+R (Mac)
  
  4. Check GPU acceleration:
     Chrome: chrome://gpu
     → All should say "Hardware accelerated"
