# Gradient Studio - User Guide

Welcome to **Gradient Studio**, a professional-grade gradient generator with advanced features, real-time animation, shader effects, and high-resolution export capabilities.

---

## 🚀 Quick Start

1. **Create a Gradient**: Use the left sidebar to select colors and adjust gradient settings
2. **Add Effects**: Switch to the Effects tab to apply visual enhancements
3. **Animate**: Enable animation in the right sidebar's Animation tab
4. **Export**: Export your creation in various formats from the Export tab

---

## 🎨 Interface Overview

### Header Bar
- **Logo & Title**: Gradient Studio branding
- **Keyboard Shortcuts Button (⌨️)**: Click to view all keyboard shortcuts
- **Panel Toggles**: Hide/show left and right panels
- **Play/Pause Button**: Control animation playback
- **Interactive Toggle**: Enable pointer-based gradient manipulation

### Left Sidebar (Controls)
Four tabs for gradient creation:

#### 1. **Gradient Tab** 🎨
- **Color Palette Selector**: 58 pre-made color palettes
- **Gradient Type**: Linear, Radial, Conic, Diamond, Spiral, Square
- **Angle/Position**: Adjust gradient direction and center
- **Color Stops**: Add, remove, and adjust color positions
- **Blend Mode**: Normal, Multiply, Screen, Overlay, etc.

#### 2. **Effects Tab** ✨
8 shader-based effects:
- **Noise**: Organic texture overlay
- **Grain**: Film grain effect
- **Vignette**: Edge darkening
- **Chromatic Aberration**: Color separation
- **Blur**: Gaussian blur
- **Glow**: Luminous aura
- **Posterize**: Color banding
- **Pixelate**: Retro pixel effect

Each effect has intensity controls (0-100%).

#### 3. **Presets Tab** 📚
- **Default Presets**: 50+ professionally crafted gradients
- **Custom Presets**: Save your own creations
- **Import/Export**: Share preset collections

#### 4. **Settings Tab** ⚙️
- **Canvas Size**: Preset resolutions (1920×1080, 4K, etc.)
- **Custom Dimensions**: Set exact width/height
- **Background**: Transparent or custom color
- **Quality**: Export quality settings

### Center Canvas
- **Live Preview**: Real-time gradient rendering
- **Interactive Mode**: When enabled, move your cursor to manipulate the gradient
- **Responsive**: Automatically scales to fit your screen

### Right Sidebar (Layers & Export)
Four tabs for advanced control:

#### 1. **Layers Tab** 📑
- **Layer Stack**: Manage multiple gradient layers
- **Visibility**: Toggle individual layers on/off
- **Opacity**: Adjust layer transparency
- **Blend Modes**: Control how layers combine
- **Reorder**: Drag to change layer order

#### 2. **Animation Tab** 🎬
- **Animation Type**: Rotation, Wave, Pulse, Zoom, Drift
- **Speed**: 0.1× to 5× playback speed
- **Intensity**: Effect strength (0-100%)
- **Direction**: Forward or Reverse
- **Easing**: Linear, Ease In/Out, Bounce, Elastic
- **Loop**: Continuous or one-time playback

#### 3. **Textures Tab** 🖼️
- **Texture Type**: None, Noise, Grid, Dots, Lines, Waves
- **Scale**: Texture size multiplier
- **Opacity**: Texture visibility (0-100%)
- **Blend Mode**: How texture mixes with gradient
- **Animation**: Texture-specific motion effects

#### 4. **Export Tab** 💾
Multiple export formats:
- **PNG**: High-quality raster (1080p to 8K)
- **SVG**: Vector format (infinite scaling)
- **CSS**: Copy CSS gradient code
- **JSON**: Save complete project data
- **Video**: Animated MP4 export (coming soon)
- **GIF**: Animated GIF export (coming soon)

### Bottom Status Bar
Real-time information:
- Canvas dimensions
- Active layer count
- Current gradient type
- Animation status
- Texture status
- App version

## 🎯 Common Workflows

### Creating a Simple Gradient

1. **Select Colors**: Click "Gradient" tab → Choose a color palette
2. **Adjust Type**: Change gradient type (Linear, Radial, etc.)
3. **Fine-tune**: Drag color stops to adjust transitions
4. **Export**: Click Export tab → Choose PNG → Download

### Creating an Animated Gradient

1. **Create Base**: Design your gradient in the Gradient tab
2. **Enable Animation**: Go to Animation tab → Toggle "Enable"
3. **Choose Type**: Select animation type (Rotation, Wave, etc.)
4. **Adjust Speed**: Set desired speed and intensity
5. **Preview**: Click Play button in header
6. **Export**: Export as video or animated GIF

### Layering Multiple Gradients

1. **Create Layer 1**: Design your first gradient
2. **Add Layer**: Click "+" in Layers tab
3. **Design Layer 2**: Create a different gradient
4. **Adjust Opacity**: Lower Layer 2 opacity to blend
5. **Set Blend Mode**: Try different blend modes
6. **Reorder**: Drag layers to change stacking

### Adding Texture & Effects

1. **Base Gradient**: Create your gradient
2. **Add Texture**: Textures tab → Enable texture → Choose type
3. **Apply Effects**: Effects tab → Enable effects → Adjust intensity
4. **Fine-tune**: Adjust individual effect strengths
5. **Export**: High-res PNG or SVG

## 💾 Saving & Loading Work

### Auto-Save Feature
**Everything auto-saves to your browser!** Includes:
- Current gradient settings
- All layers
- Effects configuration
- Animation settings
- Panel preferences

Close the browser and return later - your work will be waiting!

### Custom Presets

**Save a Preset:**
1. Design your gradient
2. Go to Presets tab → Custom section
3. Click "New" button
4. Enter a name → Save

**Load a Preset:**
- Click any preset card to instantly apply it

**Export Presets:**
1. Presets tab → Custom section
2. Click Export button (download icon)
3. Saves as JSON file

**Import Presets:**
1. Presets tab → Custom section
2. Click Import button (upload icon)
3. Select your preset JSON file

## 🎨 Advanced Techniques

### Creating Complex Multi-Layer Gradients

1. **Base Layer**: Create a simple 2-color background
2. **Accent Layer**: Add a vibrant gradient with low opacity (20-30%)
3. **Highlight Layer**: Add a bright gradient with Screen blend mode
4. **Texture Layer**: Enable subtle noise texture
5. **Effects**: Apply gentle glow for depth

### Interactive Gradient Manipulation

1. Enable "Interactive" toggle in header
2. Move your mouse/finger across the canvas
3. The gradient responds to pointer position
4. Adjust interaction intensity in settings
5. Combine with animation for dynamic effects

### High-Resolution Exports

For print or professional use:
1. Settings tab → Select "4K (3840×2160)" or "8K"
2. Design your gradient
3. Export tab → Select PNG
4. Choose quality: 100% for maximum quality
5. Download → Ready for print!

### Creating Seamless Patterns

1. Use Conic or Square gradient types
2. Set equal color stops for symmetry
3. Enable Grid or Dots texture
4. Adjust scale for pattern density
5. Export as PNG or SVG

## 🔧 Performance Tips

### Optimize for Smooth Animation

- **Reduce Effects**: Disable unused effects
- **Lower Resolution**: Use 1080p for editing, export in 4K
- **Limit Layers**: Use 2-3 layers max for best performance
- **Simplify Textures**: Lower texture opacity if sluggish

### Monitor Performance

- Press `Shift + P` to show FPS counter
- **Green (55+ FPS)**: Excellent performance
- **Yellow (40-54 FPS)**: Good performance
- **Orange (25-39 FPS)**: Fair, consider optimizing
- **Red (<25 FPS)**: Poor, reduce effects/layers

### Browser Recommendations

Best performance in order:
1. **Chrome/Edge** (Best WebGL support)
2. **Firefox** (Good performance)
3. **Safari** (macOS users)

Enable hardware acceleration in browser settings for best results.

## 🐛 Troubleshooting

### Gradient Not Showing
- Refresh the page (Cmd/Ctrl + R)
- Check if layer is visible (eye icon in Layers tab)
- Ensure browser supports WebGL

### Animation Stuttering
- Reduce effect intensity
- Lower canvas resolution
- Close other browser tabs
- Check FPS with Shift + P

### Export Not Working
- Ensure canvas is fully loaded
- Try a different export format
- Check browser console for errors
- Disable browser extensions if issues persist

### Work Lost After Closing
- Check if cookies/localStorage enabled
- Use Custom Presets to manually save important work
- Export JSON as backup

## 🎓 Tutorial: Create a "Sunset Gradient"

**Step-by-step:**

1. **Colors**: Gradient tab → Select "Warm Sunset" palette
2. **Type**: Change to "Linear" gradient
3. **Angle**: Set to 180° (top to bottom)
4. **Add Texture**: Textures tab → Enable "Noise" → Opacity: 15%
5. **Add Glow**: Effects tab → Enable "Glow" → Intensity: 30%
6. **Add Vignette**: Enable "Vignette" → Intensity: 40%
7. **Animate**: Animation tab → Enable → Type: "Wave" → Speed: 0.5×
8. **Preview**: Press Space to play animation
9. **Export**: Export as 4K PNG

**Result**: Professional animated sunset gradient!
